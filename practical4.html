Tailwind CSS Classes Used

Class Purpose
bg-gradient-to-br Creates a diagonal background gradient.
from-blue-100 Sets the starting gradient color.
via-cyan-100 Adds a middle cyan gradient color.
to-indigo-200 Sets the ending gradient color.
flex Creates a flexible layout.
justify-between Places items with space between them.
items-center Aligns items vertically in the center.
grid Creates a CSS grid layout.
grid-cols-1 Displays one column on small screens.
md:grid-cols-2 Displays two columns on medium screens.
lg:grid-cols-3 Displays three columns on large screens.
gap-8 Adds space between grid items.
rounded-2xl Creates rounded corners.
border-2 Adds a two-pixel border.
shadow-lg Adds a large shadow.
hover:shadow-2xl Increases shadow when hovering.
hover:-translate-y-2 Moves the card upward on hover.
hover:scale-110 Enlarges the image on hover.
transition-all Creates smooth transitions.
duration-500 Sets transition duration.
max-w-6xl Limits the maximum content width.
mx-auto Centers the container horizontally.
min-h-screen Makes the minimum height equal to the screen height.
